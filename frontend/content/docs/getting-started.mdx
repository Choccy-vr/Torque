New to Torque? Do these in order and you'll be ready to start logging time.

<Steps>
  <Step>
    ### Join the Hack Club Slack
    All Torque communication happens in the [Hack Club Slack](https://hackclub.com/slack/). Once you're in, join [#torque](https://hackclub.enterprise.slack.com/archives/C0BHGT33JHH) to ask questions, share ideas, and see what others are building.
  </Step>
  <Step>
    ### Check you're eligible
    Torque is for teenagers aged **13–18** (inclusive). No prior hardware experience is needed; Level 1 projects exist exactly for first-timers.
  </Step>
  <Step>
    ### Set up time tracking
    Every hour you want credit for has to be tracked.
    - **[Lapse](https://lapse.hackclub.com/)** records timelapses for CAD, PCB design, and bench work. This is the main one for hardware.
    - **[Hackatime](https://hackatime.hackclub.com/)** tracks time spent writing firmware in your code editor.
  </Step>
  <Step>
    ### Pick a project idea
    Read [What Makes a Good Project?](/docs/projects/what-is-a-good-project) and aim for something you'd actually want on your desk in five years. Not sure where it lands? Check the [project levels](/docs/projects/levels).
  </Step>
  <Step>
    ### Choose your path
    Decide whether you want a grant to buy parts (**funding path**) or you already have parts and want every hour as Volts (**no-funding path**). See [Paths](/docs/projects/paths).
  </Step>
  <Step>
    ### Create a repo and start journaling
    Make a public GitHub repo for your project, then post your first [journal entry](/docs/journaling/how-to-journal). Log early and often: daily entries build your streak.
  </Step>
</Steps>

<Callout type="success" title="That's it, go build!">
  When your design is done, follow the [shipping guidelines](/docs/shipping/shipping-guidelines) to submit it.
</Callout>
